# Assignment Three - Q5: Themed Form with TextFields and Submit Button

## Overview
This project demonstrates how to create a **login form** in **Jetpack Compose** with:

- Two **TextFields** (Username + Password).  
- **Material 3 theme styling** for colors and typography.  
- **Validation logic** that shows error text when fields are empty.  
- A **Submit button** that displays a success message when both fields are filled.
